# semtx

Semantic CSS library for the modern web

## Quick Start

Use CDN:

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/madeonawave/semtx@main/semtx.css">
```

Or, 
Download `semtx.css` and include it in your HTML:

```html
<link rel="stylesheet" href="semtx.css">
```

For usage examples, visit <a href="https://semtx.org"> semtx.org</a>
